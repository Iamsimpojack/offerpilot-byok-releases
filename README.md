## Giving a friend access

The owner grants complimentary access in the hosted app's **Admin → Complimentary access**, using the email the friend will verify. The owner copies the setup message and sends it personally; granting access does not send an automatic email. Share this repository's [setup guide](SETUP.md) with the download link.

The friend uses the same installer and signs in with that email. If needed, use **License options → Refresh license**. No gift code or private GitHub invitation is required. Provider usage is paid by the friend.

The hosted complimentary-access feature and a qualified installer must be available before this handoff is ready.
