## When releases are available

1. Download the installer matching your platform from [Releases](https://github.com/Iamsimpojack/offerpilot-byok-releases/releases). Each release will list its verified OS versions and audio configurations.
2. Follow the setup guide linked in that release, sign in and verify your email. Use the email selected for your complimentary access, if applicable.
3. Add provider keys and check audio permissions. Activate a paid or complimentary license, then complete a practice rehearsal.

Only qualified stable installers and their update metadata are published. Windows uses a signed installer; Mac uses a signed and notarized application. Updates use this same repository. No GitHub tokens are required on your computer.
