## Giving a friend access

The owner grants complimentary access in the hosted app's **Admin → Complimentary access**, using the email the friend will verify. Use the setup instructions emailed by the owner or shared directly. If they don’t arrive, ask the owner to resend or share the invite.

The friend uses the same installer and signs in with that email. If needed, use **License options → Refresh license**. No gift code or private GitHub invitation is required. Provider usage is paid by the friend.

For this preview, share the direct GitHub release link. The hosted app also offers the friend-preview installers after sign-in.

## Automatic updates

Install the 1.8.5 preview manually once to join automatic preview updates. After that, the app checks when it starts and every four hours while open. New versions download in the background. An **Update Ready** message offers **Restart Now** or **Later**; it will not force an immediate restart. If you choose Later, the update installs when you normally quit. Finish and save your current work before restarting.
